## Structure

- `seats/` — Round 1: eleven chairs, each a distinct lens, every claim
  code-or-doc cited. Cartographer (promise vs reality), Visionary (big moves),
  Contrarian (against the pile), Optimist (latent leverage), Hole-Finder
  (day-in-the-life coverage), Operator (presence/UX), Coach (training craft),
  Business (road to client #1), Steward (autonomy/trust), Engineer
  (load-bearing structure), Archivist (the memory stack).
- `sweeps/` — six file-by-file territory sweeps covering EVERY file in the
  repo: core spine, the mind, the business stack, life & training, the
  frontend, tools & integrations.
- `round2/` — the chairs restarted: each read the full round-1 record + the
  sweeps, cross-examined the others, and delivered final positions.
- `SYNTHESIS.md` — the resolved program: fix-now, unlocks, next builds, big
  bets, rejected — with the evidence trail.
