## 1) Rulings on the four defects — as a coach, not an engineer

**The plate-notation contradiction (`volume.ts:106` vs `:131`) — worse than the sweep said.** The docstring says "2 plates + 25" → 115 (total plates); the code computes 205 (per side, ×2); and *real gym speech* means neither — "2 plates" at any rack in America is 225, because the bar counts and the code never adds it. Every plate-notated lift flows into tonnage, week-over-week deltas in the reasoner's [VOLUME] paragraph, and Brzycki e1RM — which means **false PR announcements built on a number the coach never said**. In front of athletes this is the worst class of error: the record wall and the PR callout are *public* trust artifacts. The first time a kid catches a wrong number on the wall, the system becomes "Coach's app is broken" and no later fix un-rings it. Ruling: the fix is not picking an interpretation — it's **refusing to guess**. Ask Cole once, store his convention as a knowledge fact, and until then quarantine plate-notated loads from tonnage/e1RM (report "unparsed load" honestly, per hard rule 3). A blank is recoverable; a confident wrong PR is not.

**Observations-only lock is prompt-only (`reasoner.ts:677`) — this is the safety line, not a credibility line.** One hallucinated "next week run 5×5 @ 205" is written by `sessionFeedback.ts:84-91` to the athlete's sheet *before* Cole has necessarily read it (write-then-show, best-effort). The sweep's fix (deterministic prescription-scanner — future-tense load/set/rep regex — before any `write_feedback`) is days of work. Ruling: **no feedback write to any shared surface until the scanner exists.** Non-negotiable.

**"Cole's eyes only. Athletes never see this" (`reasoner.ts:672`) — the prompt licenses candor the audience can't survive.** Feedback voiced for the coach's ear ("he sandbagged the back half," fatigue speculation, comparisons) lands in the kid's own sheet, parent-readable for minors.
