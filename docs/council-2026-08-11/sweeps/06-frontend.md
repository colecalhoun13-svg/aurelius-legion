## Top findings by severity

1. **The auth story is one dormant env var deep.** Every one of the 41 API routes is unauthenticated at the route level and imports the brain directly — `middleware.ts` is the sole gate and returns `NextResponse.next()` when `APP_UNLOCK_SECRET` is unset (middleware.ts:54-55). A deploy that misses the var exposes anonymous writes to **autonomy grants** (`/api/autonomy/dial` POST `op:"grant"`), `confirmAction`, corpus ingest/delete, and all CRM money writes. The lock itself is well built (derived-token cookie, timing-safe, safe `?next`), and the public exemptions (`/start`, `/standard`) are genuinely narrow — but nothing at runtime asserts "production ⇒ secret present."
2. **The funnel's minted links point at the wrong origin.** `business/page.tsx:1203-1204` builds probe links as `${window.location.origin}/l/${code}`, but `/l/:code` is served only by the backend Express app (`aurelius/index.ts:256`); the frontend has no `/l/` route, no rewrite, and no `PUBLIC_PATHS` exemption. On the two-service deploy, "copy link" hands Cole a URL that 404s — or, with the lock armed, shows a prospect the `/unlock` door ("This mind answers to one operator"). A lead-losing dead door on the page built to refuse fake progress.
3. **The Decisions bench loses Cole's input and swallows failures.** `SignalsBench.tsx:179-187` `correct()`: the `/api/corrections` POST result is never checked, then `act(id,"dismissed")` runs unconditionally — if the correction write fails, his typed teaching vanishes *and* the signal is dismissed. Also `act()` (SignalsBench.tsx:166-175) and `TriageQueue.tsx:69-78` `route()` surface nothing on non-OK — the card just sits there as a dead tap — and `act()` has no busy-guard (double-fire on slow taps). Contrast: Home's identical actions flash errors and keep input.
4. **`/api/upnext` mirrors a stale cron roster** (upnext/route.ts:12-22): missing 05:30 inbox triage, 07:30 outreach sweep, and Mon 06:50 trend sweep from the CLAUDE.md spine. Home's "Aurelius's next move" line is wrong every morning between 07:00-08:00. Home's own `JOB_HOURS` (home/page.tsx:103-115) *does* have them — the two hand mirrors already disagree; the Tuning `SPINE` list is a third copy.
5. **Settings lies when `NEXT_PUBLIC_BACKEND_URL` is unset** (settings/page.tsx:109-119): `backendUrl()` falls back to `http://localhost:3001`, so on a deployed phone the health dot reads "backend unreachable" (false) and all three OAuth Connect links point at localhost — dead buttons with no message naming the missing env.

**Smaller defects:** AutonomyPanel's "show older" toggle renders only when the 7-day list is non-empty — an empty week hides the only door to the 90-day undo history (AutonomyPanel.tsx:228-239, rule 8). `.au-chambers` has no mobile fallback: five fixed columns at 390px clip/overlap the tracked caps labels (globals.css:924-939). ShelvesPanel book spines are clickable `div`s — keyboard-unreachable (ShelvesPanel.tsx:156-160; the Catalog view redeems it). `AskPanel.tsx:95-103` drops a repeated identical ⌘K ask. `/crest/*.png` isn't in `PUBLIC_PATHS`, so the locked-device boot animation is a black screen. `useNeedsYou` runs twice (TopBar + MobileTabBar both mounted). Boot-image note aside, `window.alert`/`window.prompt` vs inline flash lines are two competing error grammars.

## Where does the UI lie to Cole or lose his input?

Honestly: less than almost any codebase this size — "unreachable ≠ empty" is enforced nearly everywhere (business, athletes, goals, calendar, wiki, home all distinguish), inputs clear only on confirmed saves (Home capture, MissionsPanel launcher), and dormant states name their env var. The residual lies are: the stale `upnext` roster (daily), the Settings localhost dot (deploy), the wrong-origin `/l/` links (silent funnel damage), and the badge/hero counts if the middleware env is missed. The residual input losses are exactly two: `correct()` on the bench, and silent non-OK on bench/triage rulings.

## Three best opportunities

1. **One shared mutation helper.** The same ~25-line `setBusy/try/fetch/parse/setErr` block is hand-copied ~25 times; every real bug found (correct(), act(), route()) lives where a copy diverged. A single `usePost()` with busy-guard, error surface, and receipt semantics would fix all three and shrink the big pages materially.
2. **Make the minted links real:** a Next rewrite of `/l/:code` → `BACKEND_ORIGIN` (plus `PUBLIC_PATHS` entry) turns the probe/copy-link/bio-link story from a dead door into the working attribution loop the Business page narrates.
3. **One roster of truth for the spine:** `/api/spine` already imports `ONCE_PER_DAY`; extend it (or a sibling) to serve names+times and feed `upnext`, Home's `JOB_HOURS`, and Tuning's static `SPINE` from it — deleting three hand mirrors that have already drifted. Bonus: a production assert (or loud log) in `middleware.ts` when the lock is dormant.
